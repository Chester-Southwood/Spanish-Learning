# Spanish Learning (SRT Directory)

This is a personal directory where I store SRT files to media that I watch to help me learn Latin Spanish with episodes I have downloaded on my computer.

If anyone is interested in using these files, I recommend using the Chrome Extension: http://languagereactor.com/ It's a free tool, the paid version has more benefits, that allows you to upload your videos and subtitle files to watch. It has many features like easy word lookup, saving word lists, exporting lists, importing text, and more.

If there are any requests for SRT files, I can try to upload them if you create an issue on this repo: https://github.com/Chester-Southwood/Spanish-Learning/issues/new
